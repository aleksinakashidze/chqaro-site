# chqaro-site

Static public pages for the Chqaro apps (Google Play listing requirements): privacy policy, terms and
account-deletion instructions. Plain HTML with relative links, so it works both on GitHub Pages
(`https://<user>.github.io/chqaro-site/privacy.html`) and on Vercel. Edit `generate.js`, run `node generate.js`.

Contact address on every page: `support@chqaro.ge` (constant in `generate.js`).
